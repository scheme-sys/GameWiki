# 按需加载与性能维护

页面使用静态 HTML、CSS 和经典 JavaScript，不依赖运行时构建服务。首页只读取游戏注册表、游戏显示尺寸图标和交互脚本，不预取各游戏数据库。背景渐变保持静态，Canvas 内的星点独立移动，近邻连线随距离淡入淡出；桌面上限 128 点、30 fps，触摸端上限 48 点、24 fps，并限制 DPR 与画布像素总量。邻居搜索每半秒执行一次，每点最多 3 / 2 条连线。后台、弹窗、拖拽、系统减少动态效果和音频外层页面隐藏时暂停绘制，失败时保留已有 SVG 作为回退。

## 每次加载什么

| 页面 | 首次打开 | 用户操作后 |
| --- | --- | --- |
| 全站音乐 | 尝试自动播放当前曲目；播放被拒绝或已手动关闭时不下载音频 | 首次可信交互恢复播放；结尾前 18 秒内准备下一首，同一个播放器跨站内页面保留 |
| LCZ 首页 | 游戏图标、轻量注册表与交互 | 搜索和介绍卡复用已读数据；封面仅在首次悬停或长按对应游戏时加载，不读取 Wiki 数据库 |
| Craft | 轻量分类索引、当前页条目块 | 翻页读取对应详情块；输入搜索词才加载说明搜索索引 |
| Day R | 默认物品目录及图片映射 | 怪物分类、怪物收藏或怪物深链首次需要时读取战斗单位资料 |
| Westland Wiki | 首页卡片和分类摘要 | 分类、搜索与翻页读取完整索引；物品详情仍单独按块读取 |
| Westland 配装 | 二维配装与计算 | 主动打开 3D 试装后读取模型与渲染资源 |
| Dawn | 首页统计与精选内容 | 分类索引、详情、配方分页、收藏和各栏目分别按需读取 |
| Last Day on Earth | 首页摘要与分类数量 | 分类卡片、详情、配方关联、收藏和完整搜索分别按需读取 |
| Grim Soul | 首页 11 条摘要、计数与稳定 ID 索引 | 分类摘要、全文搜索、关联卡片与完整详情分别按需读取 |

已经成功加载的数据在当前页面复用。请求失败时显示可重试状态；快速切换搜索、分类或详情时，仅当前操作可以更新界面。没有定时器在首页空闲后偷偷下载整个数据库。

目录缩略图使用共享 `assets/lazy-images.js`：距可视区域 100px 内才填写实际图片地址，首屏图片立即请求；滚动时补齐后续图片，列表重绘时清理已移除节点的观察。不支持 IntersectionObserver 时正常加载所有当前列表图片。保留原图片、尺寸和详情展示，不以压缩画质换取加载速度。Westland 保留已有同类加载器。

首页黄金树背景仍立即展示且只选择当前屏幕对应的一张图片；鼠标首次触发局部点亮时才提取黄金纹理，本地文件的对应遮罩图也在此时加载。尚未使用鼠标点亮时不启动纹理 Worker 或下载遮罩。

## 更新和发布

- 维护源与浏览器分片分开保存。更新内容后执行对应游戏 README 中的生成命令，再执行验证命令；不要只手动更改某个生成分片。
- Dawn、Craft、LDOE 和 Grim Soul 的全量维护 JS 不进入 Pages 发布包，浏览器仅使用摘要与按需分片；完整维护资料仍留在仓库。
- HTML 中 CSS/JS 的版本参数由打包脚本生成。动态分片的版本由各游戏生成器维护，使用内容哈希文件名或内容哈希查询参数。一次发布包含清单及它引用的全部分片。
- 普通脚本加载兼容 HTTP 与本地 `file://`，继续遵循已有 CSP，不增加外部数据库服务。
- 介绍卡封面使用 `assets/game-covers/` 的 WebP 显示副本，首页 HTML 不填写封面 `src`，不预读其他游戏封面。切换时忽略旧图的迟到解码结果；加载失败保留完整深色介绍卡，不阻塞进入 Wiki。Craft 与 Westland 的 Wiki 首页共享对应封面，Dawn 首页也复用对应轻量封面；其余游戏原有首页封面不变。
- 原始游戏图片保持不变。主页使用 `assets/game-icons/display/` 的 384px 显示副本；运行 `python scripts/build-game-icons.py` 可重新生成，开发环境需要 Pillow。

游戏资料、数值、关系、收藏 ID、下载文件与模型映射均有完整性校验。数据清理边界见 [player-data.md](player-data.md)，加载优化不能把被清理的原始实现字段重新混入发布包。

## 验证方式

在独立浏览器、空缓存条件下记录首次打开产生的网络请求，并按默认首页、分类、搜索、详情、收藏、配方翻页和 3D 入口分别观察新请求。检查同一功能再次打开不重复取数据，并模拟失败与延迟响应。

LDOE 接入时以空缓存核验：1440px 桌面首屏资源由 1,273,628 字节降至 267,308 字节，390px 手机由 1,252,248 字节降至 245,928 字节；分别减少约 79% 和 80%。首屏数据为 35,939 字节，分类、详情及搜索等 108 个分片在相应操作后读取。后续内容更新可能改变体积，可运行 `scripts/test-ldoe.py` 复核首屏请求与按需加载边界。

Grim Soul 接入时以空缓存核验：1440px 桌面首屏资源从 2,221,838 字节降至 327,951 字节，390px 手机降至 314,337 字节；分别减少约 85% 和 86%，已包含共享 LCZ/QQ群组件。首屏数据为 49,524 字节，186 个分类、摘要、详情和搜索分片在相应操作后读取；原资料与图片完整保留。

网络体积报告使用本地 HTTP 服务的未压缩响应体字节。它反映实际需要下载的内容量，不代表 GitHub Pages 的压缩后流量或所有用户的加载时间。真实耗时还受网络、缓存、设备和服务响应影响。

主页交互验证覆盖 320px 手机窄屏、横屏、平板、桌面、触控长按与取消、键盘操作、减少动态效果和后台停帧。气泡拖动时允许重叠，邻居不会阻挡指针；松手后用阻尼动画分离，保存最终落点，避免刷新恢复重叠。介绍卡在分离完成后才响应鼠标悬停，防止打断动画。气泡物理测试覆盖 15/30/60/120fps、长时间漂移和连续急拖；渲染循环只写 transform，不逐帧读取布局。

Dawn 首页以同构图 WebP 替换显示用 PNG（原图保留）：封面由 670,798 字节减至 58,200 字节，减少 612,598 字节；本地首屏实测约减少 44.8%。音乐只加载获准播放的当前曲目及临近切歌时的下一首。音乐模块和跨页导航的边界见 [music.md](music.md)。

## Westland 配装与分析分工

配装实验室保留原网址 `westland_difficulty_design.html`，只呈现配装、方案对照、补给技能与对战；七档难度、刷怪图鉴、装备演算、人型套装和无尽成长位于 `westland_difficulty_analysis.html`，主实验室仅通过一个按钮进入。分析页不加载配装控制器、战斗引擎或 3D 资源；主实验室不加载分析控制器和分析 DOM。

两页共用 `wiki-assets/lab/difficulty-model.js` 中的计算规则。分析页的难度、原版等级和分位保存在当前标签页会话中；返回实验室后更新提示，只有点击“套用难度强化”才修改配装。3D 试装仍需主动开启。物品、动物、技能资料及原始图片保持同一份来源。
