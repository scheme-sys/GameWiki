# 基地网页原型维护说明

本文说明本网站的基地设计原型，不记录游戏内部类、方法、资源表或提取地址，也不声称网页程序就是游戏的实现。

基地设计区分“获得位置情报”和“进入基地”。再次进入应恢复当前实例，不能通过反复进出重新生成奖励。地图使用可复现的种子与预设布局模块，结合主题、难度和防守预算形成预览；它不表示游戏采用相同的数据结构。

维护时保留以下体验约束：

- 已选主题、难度、种子与生成结果保持一致；刷新后恢复的是该实例。
- 守卫、容器、建筑和掉落各有稳定的网页关联标识，避免重复生成或串到另一座基地。
- 玩家死亡且尚有物品待取回时，不能把实例当作已结束而清除。
- 结束基地是一项明确操作，应提示尚未取走的物品和未保存的变化。
- 预览导出采用可读摘要；本地保存仅属于此网页演示。

页面文字与控件位于 `../基地.html`；地图生成、状态转换和界面交互分别位于 `../wiki-assets/base/base-design-engine.js` 与 `../wiki-assets/base/base-design-ui.js`。这些文件中的函数和状态名由网站自身使用，维护时需与浏览器测试一起更新。

原先保存在本文中的原游戏实现名称与资源结构细节已经删除。后续补充说明应使用玩家能理解的规则或本网站自己的接口，避免重新记录无用的原始技术来源。
